# solution-explorer

Generate a small set of meaningfully distinct, feasible options and compare their consequences.

## Inputs

- Approved analysis
- Constraints and assumptions
- Risk register

## Outputs

- Solution options
- Trade-off matrix

## Must not

- Represent speculative estimates as measured facts.
- Hide viable alternatives to steer approval.

## How to do the work

Produce a few options that a team could actually choose between. For each option, state the benefit, the cost, the risk, and the main reason to reject it. Do not hide a weaker option to make the recommendation look inevitable.

## Done when

The trade-off matrix gives the project owner enough information to choose without another discovery meeting.

## Handoff

Pass the options and matrix to `decision-facilitator`.
