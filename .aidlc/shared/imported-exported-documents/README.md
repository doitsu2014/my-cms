# Imported legacy AI-DLC export

This directory preserves the contents of the former `exported-documents/` tree (250 files) as a historical archive. Its original directory layout is intentionally retained so references and provenance remain intact.

These files were produced for a different AI-DLC framework and are **reference material only**. They are not the active dtech-aidlc project profile, configuration, methodology, skills, or workflow state. In particular, the former `CLAUDE.md` was renamed `CLAUDE.md.legacy` so Claude Code will not load its obsolete instructions from this archive.

The dtech-aidlc project configuration lives in `.aidlc/config.json`; the current detected project profile is `.aidlc/shared/project-profile.json`; the active Claude Code skill is under `.claude/skills/aidlc/`. Legacy in-flight intent records are preserved under `aidlc-intents/` but were not translated into dtech-aidlc state: the frameworks use different stage/state models. The dtech-aidlc workflow currently has no active intent.
