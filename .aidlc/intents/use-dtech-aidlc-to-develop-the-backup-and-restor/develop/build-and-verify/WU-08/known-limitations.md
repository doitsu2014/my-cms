# WU-08 known limitations

- **Status:** WU-08 Done-when criteria are met; the items below are bounded limits or work owned by later units, not unmet WU-08 criteria.
- **Production composition (WU-10):** `DomainBackupService::register_routes` creates `BackupApiState` without a started `Runtime`; until WU-10 wires runtime start after migrations, production read/create return 503 `BACKUP_NOT_READY` and IF-11 reports `not_ready`. Gateway auth ordering, effective bind, CFG-17/CFG-18 ingress layers, CORS/cookie and composed-router security are WU-10 (TS-03, TS-07, TS-08b, TS-55).
- **Reconciliation fields:** IF-11 `reconciliation.last_completed_at` is always `null` and `last_result` is derived from the runtime state (`ok` / `not_run` / `degraded`). The contract type allows `null` and no registered TS asserts a timestamp; recording the completion time needs a read accessor on the lifecycle `Runtime` (WU-17..WU-19 code) and is a follow-up.
- **Metrics:** TS-57 counters are in-memory with the closed label set; no OTLP/exporter is wired. No exporter interface is designed for U1; any exporter wiring must keep the same closed label set.
- **Canary:** API-output TS-17 covers success, validation error, denial, replay, conflict and store-outage paths over response bodies/headers, captured `tracing` events (positive control proven), metrics, status and every column of the five `backup_*` tables. Token headers are excluded by design (pre-existing `domain_auth` reflection, test strategy). The web bundle scan is WU-15.
- **Create concurrency:** route-level conflict is sequential; concurrency races and audit-outage atomicity are WU-07 (TS-13, TS-14a/b, TS-15, TS-16).
- **Request rejection:** TS-60..TS-63 are covered for IF-02/IF-03/IF-04 inputs named in the test strategy; not every axum transport edge combination is enumerated. The standalone `json_rejection` helper is not wired to an extractor (the handler reads bytes and parses strictly).
- **Platform:** Re-verified on macOS (Darwin 25.6, Docker 29.9.3, PostgreSQL testcontainers). Attempt 1-3 evidence was produced on Windows 11; those evidence logs are not present in this checkout. The test-only temp-dir fix keeps Windows on the raw temp path.
- **Docker flake:** one workspace Docker run failed a WU-17 runtime test with testcontainers `PortNotExposed` during container start (infrastructure, not code); the rerun on the same tree and the final run passed 208/208. Kept as `evidence/regression-wu08-macos-ignored-run1-infra-flake.log`.
- **Rollback:** source and test changes only; no data, schema or migration rollback required.
